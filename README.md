Architecture

Compare and contrast the types of frontend development you used in your full stack project, including Express HTML, JavaScript, and the single-page application (SPA).

The Express frontend uses server-side HTML and reloads pages when users interact with it. The Angular SPA runs in the browser and updates the page without reloading, which makes it feel faster and more interactive.

Why did the backend use a NoSQL MongoDB database?

MongoDB was used because it works well with JavaScript and allows flexible data storage without strict schemas.



Functionality

How is JSON different from Javascript and how does JSON tie together the frontend and backend development pieces?

JavaScript is used to build application logic, while JSON is a simple data format that allows the frontend and backend to exchange information.

Provide instances in the full stack process when you refactored code to improve functionality and efficiencies, and name the benefits that come from reusable user interface (UI) components.

The code was refactored by separating API logic into services and using reusable components, which made the application easier to maintain and update.



Testing
